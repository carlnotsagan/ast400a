a. - Analytical stellar density profile#

Imagine a star has a density profile of the form:

\[\rho(r) = \rho_c \left [ 1 - \left (\frac{r}{R_\star} \right )^2 \right ]\]

where \(\rho_c\) is the central density.

Also, the formulation for the mass equation (a form of the eqn on Slide 5 of the Lecture)

\[ M(r) = \int^{r}_{0} 4 \pi r^2 \rho dr \]

Individually/with the person next to you:#

  1. Create function for \(\rho(r)\) using Sympy and the defined symbols.

  2. Integrate the mass equation to find \(M(r)\) using sympys integrate function evaluated from 0 to \(R_\star\) (defined above).

  3. Next, we want to solve for \(\rho_{c}\) by setting \(M_\star\) to the \(M\) we computed in 1 using sympys Solve function.

Hint: in sympy you can set define an equality using Eq relation function. For example to set the LHS of an equation to the RHS, you would write Eq(LHS,RHS).

  1. Next, confirm that the average density of this star is \(\bar{\rho}=0.4\rho_{c}\), assuming \(\bar{\rho}=M/V\).

Hint: for fractions in sympy you would use the Rational function.

  1. Next, use substition again to plug in the solar radius and mass in cgs and evaluate \(\rho_{c}\) using evalf to make an estimate for the central density with the equation we found in 2.

  2. Confirm that \(\bar{\rho}\approx 1.4 \ (\rm{g \ cm}^{-3})\) for this density profile using the numerical value found in 4. and Subs. Similar to the Sun.
