b. Visualizing \(pp\)-chains using pynucastro and importance of PP-I vs. PP-II#

Individually/ with the person next to you:#

To produce plots in this exercise we will use pynucastro

There are multiple proton-proton chains.

  • PP-I involves: \(p\), \(d\), \({}^3\mathrm{He}\), \({}^4\mathrm{He}\)

  • PP-II adds: \({}^7\mathrm{Li}\), \({}^7\mathrm{Be}\)

  • PP-III adds: \({}^8\mathrm{Be}\), \({}^8\mathrm{B}\)

Here we can explore them all.

Creating a network

We’ll use pynucastro to create a network with all of these nuclei using the network_helper to Generate a basic network connecting all of the input nuclei using all of the rates known to pynucastro.

Note

ReacLib does not provide the rate for \({}^8\mathrm{Be} \rightarrow \alpha + \alpha\) because it is so short lived. It essentially will break apart into two \(\alpha\) immediately. It instead has a rate that combines:

\[{}^8\mathrm{B} \rightarrow {}^8\mathrm{Be} + e^+ + \nu_e\]
\[{}^8\mathrm{Be} \rightarrow \alpha + \alpha\]

  1. Create our net for the above listed nuclei for our \(pp\)-chain burning.

  2. Esimtate the solar composition (\(X,Y,Z\) etc.) at its current age.

    • We can do this by setting the initial composition of the Sun (\(X_{0,i}\))

    • then integrate the network using Scipys solve IVP solve_ivp to the Sun’s current age tmax.

  3. Now, we will use the current composition \(X_{i}\) and evaluate the rates using the \(T_{c}\), \(\rho_{c}\), and our composition using evaluate_rates

  4. Produce the same plot but now for a higher temperature of \(T_{6}=35\).
